# Printer problems

Applies to: can't print, print jobs stuck, printer offline, poor print quality.

Steps for the user:
1. Check the printer screen for paper jams, low toner, or error messages.
2. Make sure you picked the correct printer name from the list (floor and room number).
3. Cancel stuck jobs in the print queue, then try printing a single page.
4. Remove and re-add the printer from Settings > Printers & scanners.

If the printer shows offline for everyone, the help desk will check its network connection.
