# Outlook and email problems

Applies to: Outlook not syncing, missing emails, shared mailbox not visible, calendar issues.

Steps for the user:
1. Check whether email works in the browser at https://outlook.office.com. If it does, the problem is the Outlook app.
2. Close Outlook fully, then reopen it. Check the bottom bar says "Connected".
3. For a missing shared mailbox, wait 60 minutes after access is granted, then restart Outlook.
4. Check your Junk folder and any inbox rules that might move messages.

If nobody in a team can open a shared mailbox, the help desk will check the mailbox permissions in the admin center.
