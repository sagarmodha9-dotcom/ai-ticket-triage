# Phishing and suspected security incidents

Applies to: suspicious emails, clicked a phishing link, entered a password on a fake site, possible malware or ransomware.

Steps for the user, right away:
1. Do not click any more links or open attachments from the message.
2. If you entered your password on a suspicious page, report it immediately; the help desk will reset your password and sign you out everywhere.
3. If you see a ransom message or files being renamed, disconnect from Wi-Fi and unplug the network cable, but do not turn the computer off.
4. Use the "Report phishing" button in Outlook for suspicious emails.

All suspected security incidents are escalated to the security team immediately.
