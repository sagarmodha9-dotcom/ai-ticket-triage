# Software installs and access requests

Applies to: requests for new software, licenses, or access to a system or shared folder.

Steps for the user:
1. Check the Company Portal app first; approved software can be installed there without admin rights.
2. For software not in the portal, submit a request with the business reason and your manager's approval.
3. For access to a system or shared folder, include the exact name and the level of access needed (read or edit).

Typical turnaround is 2 business days after manager approval.
